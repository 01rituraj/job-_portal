# Job Portal Website

## 📌 Project Overview
The Job Portal Website is a web development project built using HTML5 and CSS3. It provides a clean and user-friendly interface for exploring job opportunities, browsing job categories, and accessing login and registration options.

## ✨ Features
- **Navigation Bar:** Home, Browse, Jobs, and About sections.
- **Hero Section:** Attractive headline with a job search input.
- **Job Categories:** Frontend Developer and Backend Developer options.
- **Login & Register:** Buttons for user access options.
- **Loading Animation:** CSS-based animated loader.
- **Footer Section:** Copyright information, Privacy Policy, and Terms of Service links.
- **Responsive Styling:** Flexbox layout and custom CSS styling for the interface.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Font Awesome 6.5.0

## 📂 Project Structure
```text
job-portal-website/
```

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Keep `index.html` and `style.css` in the same directory.
3. Open `index.html` in any modern web browser.

## 🎯 Project Objective
The objective of this project is to practice HTML page structure, CSS styling, Flexbox layouts, navigation design, and basic frontend development concepts.
